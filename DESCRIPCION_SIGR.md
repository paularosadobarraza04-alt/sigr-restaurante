# Sistema Integral de Gestión de Restaurante (SIGR)

## 1. Descripción del proyecto

El SIGR es una aplicación web propuesta para organizar las actividades de un restaurante, como la administración de usuarios, los pedidos, las reservas, el menú, la caja y los reportes de ventas.

## 2. Objetivo

Facilitar la gestión de las actividades diarias del restaurante y mantener la información organizada, segura y disponible para los usuarios autorizados.

## 3. Módulos del sistema

- **Autenticación de usuarios:** acceso para clientes, meseros y administrador.
- **Menú digital:** administración de platos y categorías.
- **Pedidos:** registro y seguimiento de pedidos.
- **Reservas:** registro de reservas por fecha y hora.
- **Caja y reportes:** control de pagos, cierre de caja y consulta de ventas diarias.

## 4. Gestión de configuración

El proyecto utilizará Git para registrar los cambios del código fuente y GitHub para alojar el repositorio y facilitar el trabajo colaborativo.

## 5. Criterios para establecer la línea base

Antes de aprobar la línea base, se verificará que los módulos implementados funcionen correctamente, que se hayan realizado pruebas básicas, que el código esté organizado y que la documentación técnica esté disponible.

## 6. Estado del proyecto

Actualmente, el repositorio contiene la documentación inicial. Los módulos funcionales deberán desarrollarse y probarse antes de declarar una versión estable del sistema.
